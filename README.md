# Дом Олеси

Статический сайт-поздравление. HTML, CSS и JS. Без сборки и без сервера.

## Как выложить на GitHub Pages

1. Создай новый репозиторий, например `dom-olesi`.
2. Залей в корень репозитория содержимое этой папки так, чтобы `index.html` лежал в корне.
3. GitHub → Settings → Pages → Source: `Deploy from a branch` → ветка `main` → папка `/ (root)`.
4. Через минуту ссылка будет вида `https://USERNAME.github.io/dom-olesi/`.

Если репозиторий называется `USERNAME.github.io`, сайт откроется сразу на домене без имени папки.

## Двери

- Мирон: `лысый персик`
- Глеб: `киндер сюрприз`

Регистр и лишние пробелы не важны. После верного ввода обоих ключей дом запоминается в `localStorage`, чтобы маме не вводить пароли снова.

## Музыка

Кнопка «Музыка» ищет файл `assets/music.mp3`. Если файла нет, сайт не ломается — кнопка просто напишет, что файла нет. Положи туда любой спокойный трек, на который есть права.

## Фото

Лежат в `assets/photos/`. Нужные имена:

- `olesya-sad.jpg` — сад
